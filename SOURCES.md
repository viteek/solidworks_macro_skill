# Sources and attribution

The maintained [source index](references/source-index.md) records CodeStack, CADSharp, Edgarev and official SOLIDWORKS documentation, task/API mappings, published version evidence, current local test status and reuse restrictions. Source metadata was checked on 2026-11-01.

The Python result verifier, paired benchmark evaluator and 24 task contracts were written for this repository. They do not contain copied third-party macro implementations. They evaluate supplied evidence and do not establish live SOLIDWORKS compatibility by themselves.

Before importing any example code, inspect the exact file/revision and its license. CodeStack's repository advertises MIT; CADSharp permits certain personal macro reuse but restricts public reposting; Edgarev publishes GPL-3.0 code. Preserve attribution and applicable notices when reusing code. Access to a downloadable macro is not permission to redistribute its source. See the linked publisher terms in the index for the actual conditions.

Historical SOLIDWORKS 2024 SP5 environment notes and external author's tested-version claims are not certification. The [compatibility matrix](references/version-compatibility.md) and [evidence requirements](benchmarks/README.md) keep source review, installed API checks, whole-project VBA compilation, runtime, results and safety separate.
