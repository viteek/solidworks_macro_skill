# Inspect sheet metal and cut lists

[inspect_sheetmetal_cutlist.bas](inspect_sheetmetal_cutlist.bas) is an original standalone VBA diagnostic. Import into a SOLIDWORKS VBA project with SOLIDWORKS/constants references, compile, open a part and run `main`; results go to the Immediate window (Ctrl+G). SOLIDWORKS 2018+ is required for `CustomPropertyManager.Get6`.

Inputs: active part, active configuration; useful fixtures are a multibody sheet-metal part, a weldment with cut-list folders, a normal solid part and an empty part. Expected output: solid-body names and `IsSheetMetal` results; SheetMetal thickness in meters; FlatPattern feature presence; cut-list folder member names/counts; raw and cached evaluated custom properties with result/resolved/link flags. Empty arrays are handled. Repeated feature-tree links are deduplicated by feature type/name in the single part.

This is a read-only snapshot of existing data. It does not update cut lists, flatten, rebuild, activate configurations or save. `FlatPattern` presence is not evidence of unsuppressed flattening. A cached evaluated property is not proof of freshness; retain the raw expression, status and resolution flag in any downstream report. `GetBodyCount` concerns the current folder, not descendants. Lightweight assembly bodies are deliberately outside this part-only recipe.

Negative cases: no document/wrong document is rejected; empty/ordinary solid parts report no relevant bodies/features without forcing conversion; empty cut-list folders and properties do not crash; stale cut-list information remains explicitly unverified. On a test copy, compare each member with the cut-list tree, confirm thickness against the feature definition, and repeat in a second configuration manually to demonstrate configuration scope.
