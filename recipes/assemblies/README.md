# Assembly mates and mate references

Original standalone VBA modules. Import **one** `.bas` into a SOLIDWORKS VBA macro, enable the SOLIDWORKS and constant type-library references, compile, then run `main`. Open the Immediate window with Ctrl+G. Do not combine modules into one project without choosing the intended entry point.

| Recipe | Inputs | Expected result | Negative cases |
|---|---|---|---|
| [assembly_context_mate.bas](assembly_context_mate.bas) | SOLIDWORKS 2019+; disposable assembly copy; exactly two planar faces selected on different resolved top-level component instances; at least one component floating; assembly editing mode | One coincident mate; successful rebuild; no feature errors/warnings; readback confirms mate type, two entities and both selected component names | No document, wrong document, edge/cylinder selection, same instance, nested component, both fixed: reject before creation. Conflicting existing mates: creation/rebuild/readback may fail; inspect remaining feature. |
| [mate_reference.bas](mate_reference.bas) | Disposable active part copy; one to three planar faces selected in primary/secondary/tertiary order; unique name entered in InputBox | One mate reference; populated slots equal input count; each populated slot has coincident type and Any alignment | Wrong selection count/type, nonplanar face, duplicate feature name: reject before creation. Cancel/blank name: exit. Null insertion or readback mismatch: report; feature can remain. |
| [insert_component_transform.bas](insert_component_transform.bas) | SOLIDWORKS 2019+; saved/clean nonempty assembly copy in assembly editing mode; saved/clean source part copy already open in its own window; enter its full path | One new top-level instance in the source's active configuration; identity rotation/scale and root-relative translation (0.1, 0.05, 0) meters; readback checks source, configuration, component count and first 13 transform values | Empty/dirty/unsaved assembly, missing/unopened/dirty/non-part source: reject before insertion. Fixed new instance or failed solve/rebuild/readback: report; inserted instance can remain. |

The mate and mate-reference creation macros change the in-memory document and clear selection. The mate recipe can move the floating component while solving and rebuilds the assembly. The insertion recipe adds/transforms an instance and rebuilds; `SetTransformAndSolve3(...,True)` limits the transform to the current configuration. They do not save, check out, check in, automatically float components, or undo a failed creation. Close the disposable copy without saving to discard it. These examples are deliberately bounded; nested/flexible subassemblies require a separately specified solve context.

Each module has optional `RESULT_PATH=""`. Set it to a fresh absolute log filename in an existing reviewed directory to capture failures as well as readback completion. The Unicode text file is opened **before any CAD mutation** with [CreateTextFile overwrite=False](https://learn.microsoft.com/en-us/office/vba/language/reference/user-interface-help/createtextfile-method); an existing filename is refused without replacing it or starting CAD work. The terminal line is `RESULT <recipe> PASS`, `FAIL` or `CANCELLED`. Missing/incomplete logs are not success; `RunMacro2=True` alone is not result verification. A PASS line means the recipe's bounded readback checks completed, not independent CAD acceptance. Use a fresh filename for every run and retain the raw log with fixture/version evidence. Final message boxes are suppressed when `RESULT_PATH` is configured; the name/source InputBox prompts in two recipes still require manual input.

Error handlers capture the original failure then [Resume Cleanup](https://learn.microsoft.com/en-us/office/vba/language/reference/user-interface-help/resume-statement) before protected cleanup/reporting. Selection is cleared after failures only if the recipe had changed it. No selection-access lock is acquired by these modules. A cleanup failure changes the terminal result to FAIL; logging failures are printed as `RESULT_LOG_FAILED` and require treating the run as unverified.
