# Assembly insertion, transforms and mates

Runnable original examples: [assembly_context_mate.bas](../recipes/assemblies/assembly_context_mate.bas), [insert_component_transform.bas](../recipes/assemblies/insert_component_transform.bas). Bounded positive smoke cases passed on SOLIDWORKS 2026 SP4 (34.4.0); [scope and local evidence](../recipes/assemblies/README.md) distinguish those executions from the remaining **NOT_LIVE_TESTED** matrix. Installed R2026x API checks also passed. Static checks alone establish member/argument/constant availability, not solver behavior.

## Component insertion and positioning

The official [AddComponent5 signature](https://help.solidworks.com/2024/english/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IAssemblyDoc~AddComponent5.html) is `AddComponent5(CompName, ConfigOption, NewConfigName, UseConfigForPartReferences, ExistingConfigName, X, Y, Z) As Component2`. Its source must already be loaded. X/Y/Z approximately position the component relative to its bounding box; they do not define a root-relative origin transform. Check the return object, source path and referenced configuration. The recipe requires a clean part copy already open in its own window and uses [GetOpenDocumentByName(fullPath)](https://help.solidworks.com/2024/english/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.ISldWorks~GetOpenDocumentByName.html) rather than opening or saving it automatically.

The recipe supplies `UseConfigForPartReferences=True` and the source's active configuration explicitly. The [configuration-option enum](https://help.solidworks.com/2025/english/api/swconst/SOLIDWORKS.Interop.swconst~SOLIDWORKS.Interop.swconst.swAddComponentConfigOptions_e.html) is separate from configuration names; do not hard-code numbers from third-party examples. A [top-level component count](https://help.solidworks.com/2024/english/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IAssemblyDoc~GetComponentCount.html) check rejects empty assemblies before insertion, avoiding automatic fixing of the first instance. It rechecks fixed state after insertion and never automatically unfixes a component.

[MathUtility.CreateTransform](https://help.solidworks.com/2018/English/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IMathUtility~CreateTransform.html) takes a 16-element array: 0..8 rotation, 9..11 translation, 12 scale, 13..15 unused. The example uses identity rotation, unit scale and (0.1, 0.05, 0) meters. [SetTransformAndSolve3(transform,ThisConfiguration)](https://help.solidworks.com/2024/english/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IComponent2~SetTransformAndSolve3.html) returns Boolean; **True for ThisConfiguration limits the change to the current configuration**, False affects all configurations. The transform is relative to the assembly root, and the solver may move other constrained components. Check its result explicitly against False.

[Transform2](https://help.solidworks.com/2019/english/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IComponent2~Transform2.html) provides readback; directly setting it can violate existing mate relationships. After rebuild, the recipe reacquires the newly inserted top-level instance using [GetComponentByName](https://help.solidworks.com/2024/english/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IAssemblyDoc~GetComponentByName.html), verifies source/configuration/count, and compares the first 13 [ArrayData](https://help.solidworks.com/2024/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IMathTransform_members.html) values within a numeric tolerance. A desired placement alone is not proof that mates allow it.

## Entity context and selection

A face from an underlying part belongs to a different context from the corresponding face on a particular assembly instance. [GetCorrespondingEntity](https://help.solidworks.com/2025/English/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IComponent2~GetCorrespondingEntity.html) accepts the part entity and returns the entity in that component's context. Check for Nothing. For features/sketch objects use the broader [GetCorresponding](https://help.solidworks.com/2022/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IComponent2~GetCorresponding.html) contract where supported.

The recipe instead obtains both faces directly from the active assembly selection list, verifies distinct top-level component instances using [GetSelectedObjectsComponent4](https://help.solidworks.com/2017/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.ISelectionMgr~GetSelectedObjectsComponent4.html), then clears and reselects them with `SelectData.Mark = 1`. [IEntity.Select4](https://help.solidworks.com/2020/english/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IEntity~Select4.html) explicitly requires entities from the active document context. Selection indexes are one-based; mate readback indexes are zero-based.

## Creation, fixed components and overdefinition

Use [CreateMateData(type)](https://help.solidworks.com/2020/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IAssemblyDoc~CreateMateData.html), cast to the mate-specific definition, set documented properties and call [CreateMate(data)](https://help.solidworks.com/2023/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IAssemblyDoc~CreateMate.html). For [coincident mates](https://help.solidworks.com/2019/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.ICoincidentMateFeatureData.html), marked preselection is supported. `MateAlignment` is documented from SOLIDWORKS 2019, which sets this recipe's minimum version.

[IsFixed](https://help.solidworks.com/2019/english/api/sldworksapi/solidworks.interop.sldworks~solidworks.interop.sldworks.icomponent2~isfixed.html) is a Boolean and has a top-level context restriction; the recipe rejects nested components and two fixed components. Floating is not proof of available degrees of freedom: existing mates can still make the operation redundant, inconsistent or overdefined. Do not automatically unfix components or remove constraints to make creation succeed.

Check the created feature, rebuild result and [GetErrorCode2(ByRef IsWarning)](https://help.solidworks.com/2023/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IFeature~GetErrorCode2.html). Read `IsWarning` only for a nonzero feature code. For legacy [AddMate5](https://help.solidworks.com/2025/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IAssemblyDoc~AddMate5.html), its [error enum](https://help.solidworks.com/2025/English/api/swconst/SOLIDWORKS.Interop.swconst~SOLIDWORKS.Interop.swconst.swAddMateError_e.html) uses **1 for success**, 0 for unknown error and 5 for overdefinition; never assume zero means success for every API. `ForPositioningOnly=True` does not return a mate.

Reacquire the feature after rebuild. Obtain `Mate2` through `GetSpecificFeature2`; check [Type](https://help.solidworks.com/2021/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IMate2~Type.html), [Alignment](https://help.solidworks.com/2023/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IMate2~Alignment.html), [GetMateEntityCount](https://help.solidworks.com/2024/English/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IMate2~GetMateEntityCount.html), [MateEntity(index)](https://help.solidworks.com/2016/english/api/sldworksapi/solidworks.interop.sldworks~solidworks.interop.sldworks.imate2~mateentity.html) and each [ReferenceComponent](https://help.solidworks.com/2026/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IMateEntity2~ReferenceComponent.html). A nonnull created object alone is insufficient verification.
